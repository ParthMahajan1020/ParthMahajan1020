## About Me

I'm **Parth Mahajan**, a B.Tech Computer Engineering student at **DY Patil College of Engineering, Akurdi, Pune**. I enjoy building useful web applications, solving programming problems, and exploring modern software engineering.

- Focused on full-stack development with the **MERN stack**
- Practising **Data Structures & Algorithms, OOP, and problem solving**
- Building applications with React, Node.js, Express, MongoDB, REST APIs, and authentication
- Interested in clean architecture, system design, AI integration, and modern web technologies
- Comfortable working across frontend and backend, including APIs, databases, authentication, and third-party services
- Continuously improving through hands-on projects, DSA practice, and learning
- Working toward becoming a software engineer who can design, build, and scale reliable products
